# Pyae-s-Keeb

My Keeb is a 75% keyboard with a knob and via support.
The firmware was built with QMK.

It serves as a keyboard that I can use every day to type and play games.

## Features:
- EC11 Rotary Encoder for Volume
- 82 Switches for the keys
- [VIA](https://www.caniusevia.com/) support

## Firmware
This Keeb uses [QMK](https://qmk.fm/) firmware for the code.
-82 Switches for keys
-Rotary encoder for volume

## Bom:
Here is everything needed to make my Keeb

82x Cherry MX Switches
82x DSA Keycaps
8x M3x5x4 Heatset inserts
8x M3x18mm SHCS Bolts
83x 1N4148 DO-35 Diodes.
1x EC11 Rotary Encoder
1x Raspberry Pi Pico
1x Case (2 printed parts)
